# CodeAlpha Basic Network Sniffer

## Task 1 - Basic Network Sniffer

This project was developed as part of the CodeAlpha Cyber Security Internship.

The Basic Network Sniffer is a Python-based network packet analyzer that captures packets from a network interface and displays important information about the captured traffic.

## Features

- Capture network packets
- Display source IP address
- Display destination IP address
- Identify network protocols
- Display TCP and UDP source ports
- Display TCP and UDP destination ports
- Display packet length
- Extract and display packet payload
- Detect ICMP packets
- Detect DNS traffic
- Command-line packet capture control
- User can specify packet count
- User can specify network interface

## Technologies Used

- Python 3
- Scapy
